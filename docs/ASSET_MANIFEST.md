# Spinbound 에셋 명세 (ASSET_MANIFEST)

작성일 2026-10-29 · 브랜치 `feature/graphics-overhaul`

## 0. 현재 상태

- 저장소에 **실제 아트 에셋 PNG는 0개**입니다. 지금 화면의 그림은 전부 코드(Canvas 2D)로 그린 **임시 그래픽**입니다
- 참조 이미지 `assets/references/spinbound-art-reference.png` 는 저장소에 없습니다. 받으면 이 폴더에 두고 **참조로만** 씁니다(잘라서 게임 에셋으로 쓰지 않음)
- 작업 환경에 이미지 생성 도구가 없어 PNG는 만들지 않았습니다. 아래는 제작 사양입니다

## 1. 교체 방법

1. PNG를 `public/assets/<파일>` 에 둡니다 (아래 표의 '파일' 열)
2. `public/assets/asset-manifest.json` 의 `textures` 에 `"<키>": "<파일>"` 을 추가합니다
3. 끝입니다. 같은 키의 코드 그림 대신 PNG가 쓰이고, 로드에 실패하면 콘솔 경고 후 코드 그림으로 돌아갑니다

```json
{ "version": 1, "textures": { "robot-head": "characters/robot/head.png" } }
```

## 2. 공통 규격 (ART_BIBLE §10)

- PNG-32 sRGB · **@2x** — PNG 크기는 표의 논리 크기 × 2 와 **정확히 같아야** 합니다(여백은 그 안에)
- 피벗은 논리 px(왼쪽 위 기준). PNG에서는 × 2 지점
- 외곽선 `#2B2236` 논리 약 2.2px · 광원 왼쪽 위 · 팔레트는 ART_BIBLE §2
- 연속 프레임은 크기·피벗을 모두 같게. VFX는 흰색/회색조로 그립니다(실행 중 색을 입힘)

## 8. UI · 사운드 (코드 연결 필요)

- **UI 아이콘**은 지금 `src/style.css` 의 단색 SVG 마스크입니다. 정식 아이콘은 같은 이름의 **단색 SVG**(24×24)로 받는 것이 가장 쉽습니다: 왼쪽·오른쪽·점프·별·하트·소리 켬/끔·재시작·홈·해골(게임 오버)·자물쇠·체크·시작·설정·강화·로봇·보관함·보석·깃발·공격·방어
- 로고 워드마크와 스테이지 썸네일은 지금 CSS 글자·그라데이션입니다. PNG(로고 @2x, 썸네일 220×136)로 바꾸려면 메뉴 코드 연결이 필요합니다
- **사운드**는 전부 WebAudio 합성음(`src/audio.ts`)이고 파일 로더가 없습니다. 파일로 바꾸려면 로더가 먼저 필요합니다. 필요한 효과음: 달리기 발걸음 · 구르기 시작 · 구르기 유지(루프) · 스프링 · 부스터 · 적 처치 · 코인 · 사망 · 클리어 · 점프 · 착지 · 피격 · 벽 파괴 · 줄 잡기. 권장 규격: 모노 44.1kHz, m4a(AAC)+ogg, 0.05~0.6초(루프는 1~2초 무봉합)

## 9. 제작 프롬프트 (공통 틀)

> 2D mobile platformer game asset, cute chibi robot style matching the reference sheet, thick dark plum outline (#2B2236), clean cel shading with one soft highlight, light from upper-left, palette: orange #FF8A2A, white #F7F4EE, visor black, cyan eyes #5CF2FF, **single isolated part** on a transparent background, exact canvas {PNG 크기}, pivot at {피벗×2}, no text, no drop shadow, consistent with the other parts

파츠마다 위 틀에 표의 '내용'을 넣어 만들고, 리그에 붙여 본 뒤 외곽선 굵기·색이 다른 파츠는 다시 만듭니다. 같은 파츠를 프레임별로 다시 생성한 AI 결과(모양이 흔들리는 것)는 쓰지 않습니다.
