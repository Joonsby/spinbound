# Unity 2.5D 프로토타입

Phaser 웹 게임을 Unity로 옮겼을 때 시각 품질과 조작감이 실제로 좋아지는지 확인하는 프로토타입이다.
기존 Phaser 게임(`src/`)은 그대로 두고, Unity 프로젝트는 `unity/`에 따로 있다.

- 접속: Vercel 배포 주소 뒤에 `/unity/` (기존 게임은 그대로 `/`)
- 범위: 로봇 1종 · 슬라임 1종 · 테스트 스테이지 1개 (1스테이지 앞부분을 본뜸)
- 엔진: Unity 6000.6.8f1 · URP · WebGL (앱인토스가 웹 번들이라 WebGL로 검증)

## 1. 기존 게임 구조와 이식 방식

| 기존 (Phaser) | 하는 일 | Unity 프로토타입 |
|---|---|---|
| `config.ts` PHYSICS·COMBAT·COMBO | 속도·가속·점프·대시·넉백 수치 | **그대로 재사용** — `Tuning.cs` |
| `movement.ts` | 달리기 가속·스프린트, 점프 버퍼·코요테, 더블탭 대시, 구르기 | **줄 단위 이식** — `Movement.cs` |
| `contact.ts` | 밟기·구르기 공격·접촉 피격 판정 | **줄 단위 이식** — `Movement.cs`의 `Contact` |
| `input.ts` | 손 뗀 뒤 260ms 안 재입력 = 대시, 이벤트 시각 기준 | **이식** — `GameInput.cs` (손가락별 추적, 손가락이 버튼 밖으로 나가도 유지) |
| `player.ts` | 입력 → 속도, 넉백, 무적 | **이식** — `Sim.cs`의 `PlayerSim` |
| Phaser Arcade 물리 | 박스 충돌, 중력 | **재구현** — `SimPhysics` (같은 픽셀 좌표·y 아래 방향·60Hz 고정 스텝) |
| `camera.ts` | 진행 방향 앞보기, 속도 줌, 바닥 기준 세로 고정 | **재구현** — `CameraRig` (원근 카메라 + 같은 앞보기 공식) |
| `robot-rig.ts` (2D 파츠 리그) | 로봇 그리기 | **교체** — 3D 본 애니메이션 모델 |
| `enemies.ts` 순찰 | 좌우 왕복, 화면에 보인 뒤 0.65초 후부터 피격 | **이식** — `EnemySim` |
| HUD·메뉴·저장·상점·광고 | — | **옮기지 않음** (범위 밖) |
| 100개 스테이지 데이터 | 픽셀 좌표 | 좌표계가 같아 **그대로 옮길 수 있음** (이번엔 1개만) |

**조작감을 지키는 방법**
- 시뮬레이션은 기존과 같은 픽셀 좌표와 순서로 돈다: 물리 → 접촉 → 입력.
- 수치를 1px = 0.01 Unity 단위로 바꾸는 일은 그릴 때만 한다.
- 그래서 점프 높이, 대시 거리, 판정 타이밍이 웹 버전과 같다.

## 2. 구현된 것

- **로봇**: Quaternius LowPoly Robot (CC0, 무료)
  - 본 애니메이션: Idle · Walking · Running · Jump · Punch · Death · No(피격)
  - 대시와 구르기는 공 껍질 안에서 회전하는 모습으로 표현한다.
  - 구르기로 적을 쓰러뜨리면 펀치(Attack) 동작이 나온다.
- **적**: 젤리 슬라임 (코드로 만든 3D 도형). 통통 튀며 걷고, 쓰러지면 납작해지며 터진다.
- **연출**
  - 그림자가 있는 태양광과 안개, 블룸·톤매핑·비네트 후처리(우상단 FX 버튼으로 켜고 끔)
  - 타격 파티클, 히트스톱, 화면 흔들림, 착지 찌그러짐, 구르기 잔상
- **조작**
  - ← → 점프 버튼과 키보드(←→/AD, Space/↑/W)
  - 같은 방향 두 번 톡톡 = 스핀 대시
  - 버튼은 Safe Area 안에 둔다.
- **측정 표시**: 우상단에 FPS, 프레임 시간(ms), 로딩 시간이 나온다.

## 3. 비교 체크리스트 (iPhone에서 기존 게임과 번갈아)

| 항목 | 확인 방법 | Phaser | Unity |
|---|---|---|---|
| 첫 로딩 시간 | Unity는 우상단 `load`, 웹은 첫 화면까지 체감 | | |
| 다운로드 크기 | Unity 약 10MB (압축) | | |
| FPS / 프레임 시간 | 우상단 표시. 구르기·타격 순간에 주목 | | |
| 발열·배터리 | 5분 연속 플레이 후 | | |
| 조작 지연 | 버튼을 누른 순간 반응 | | |
| 대시 성공률 | 더블탭 10번 중 몇 번 | | |
| 캐릭터 동작 품질 | 달리기·점프·피격·사망이 자연스러운가 | | |
| 타격감 | 적을 쓰러뜨릴 때 시원한가 | | |
| 화면 읽기 | 적·구덩이가 잘 보이는가 (원근 때문에 거리감이 달라짐) | | |
| 토스 앱 안에서 | 앱인토스 샌드박스에서도 같은지 (WebGL 메모리) | | |

## 4. 아직 검증하지 못한 것

- iPhone 실기기의 FPS·발열·메모리 (브라우저 미리보기에서만 확인)
- 토스 앱 WebView 안에서의 동작 (앱인토스 Unity SDK 연동 전)
- 효과음·배경음 (아직 없음)

## 5. 전환 비용 (추정)

| 영역 | 작업 | 규모 |
|---|---|---|
| 게임 규칙 | 이동·전투는 이식 완료. 남은 것: 콤보 보상, 돌진·비행·점프 적, 스프링, 로프, 이동 발판, 부서지는 벽, 용 추격·도둑·타임어택 모드 | 중 |
| 스테이지 | 픽셀 좌표가 같아 변환 스크립트로 100개 일괄 이식 가능. 3D 지형 연출은 따로 | 중 |
| 메뉴·HUD | 로비, 스테이지 선택, 출석, 상점, 강화, 캐릭터, 일시정지, 결과창 전부 새로 (한글 폰트 포함) | **대** |
| 저장·플랫폼 | 진행 저장, 클라우드 저장, 앱인토스 SDK(로그인·광고·결제), 원스토어 | 대 |
| 아트 | 로봇 캐릭터 여러 종, 몬스터, 테마 3종 배경, 이펙트 | **대** (가장 큰 변수) |
| 성능 | WebGL 3D는 웹 2D보다 무겁다. 저사양 폰·토스 WebView 최적화 필요 | 중 |

**판단 기준**: iPhone에서 이 프로토타입이 기존보다 확실히 좋아 보이고, 60 FPS 근처를 유지할 때만 전환을 진행한다.
